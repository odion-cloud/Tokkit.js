Introduction

A TypeScript/JavaScript client for TikTok's internal Web and Short Drama APIs. Runs on Node.js, Deno, Bun, modern browsers, and more.

Getting Started

Prerequisites

TokKit runs on Node.js, Deno, Bun, and modern browsers.

It requires a runtime with the following features:

  • fetch: Native fetch implementation (Node.js 18+, Bun, Deno, modern browsers).
  • WebCrypto: Standard crypto.getRandomValues for token entropy.
  • EventTarget: Standard EventTarget and CustomEvent APIs.

Installation

sh
12345678 
# NPM
npm install @odion-cloud/tokkit.js

# Bun
bun add @odion-cloud/tokkit.js

# Deno
deno add npm:@odion-cloud/tokkit.js

Basic Usage

ts
1234567 
import { TokKit } from '@odion-cloud/tokkit.js';

// Initialize client session (auto device registration & tokens)
const tokkit = await TokKit.create();

const trending = await tokkit.shortDrama.getTrending();
console.log(trending);

Configuration Options

You can customize the client session by passing an options object to TokKit.create():

lang (string)
  • Description: Language locale for session requests.
  • Default: en
location (string)
  • Description: Geolocation region code (e.g. US, GB, FR).
  • Default: US
user_agent (string)
  • Description: Custom User-Agent header string.
  • Default: undefined (auto-generated modern browser User-Agent)
proxy (string)
  • Description: HTTP or SOCKS5 proxy URL for egress requests.
  • Default: undefined

Architecture

TokKit is designed around zero-dependency web standards (Fetch API, WebCrypto, ESM) to run universally across any runtime.

Multi-Runtime Support

TokKit detects and runs transparently across modern JavaScript runtimes without polyfills or native binary add-ons:

  • Node.js 18+: Uses built-in undici-backed native fetch and node:crypto.
  • Bun & Deno: First-class native ESM execution out of the box.
  • Browser & Edge: Zero Node-only API leaks, runs seamlessly in Cloudflare Workers and standard web workers.

Session Lifecycle

Upon calling TokKit.create(), the client executes an initial handshake with TikTok's gateway:

  1. Acquires anonymous guest cookies (ttwid, msToken).
  2. Initializes device hardware spoofing parameters (screen width, platform, language).
  3. Instantiates internal service modules (shortDrama, feeds, resolver).

Short Drama Overview

Reverse-engineers TikTok's official /shortdrama web portal for querying miniseries, rankings, release dates, and video streams.

Available Endpoints

The tokkit.shortDrama module exposes direct access to all portal data:

  • Trending & Ranking: Top series by weekly and daily view count.
  • Latest Releases: Chronologically sorted new short drama releases.
  • Genres & Themes: Dynamic 18 genres and 28 themes filter taxonomy.
  • Episode Playlists: Complete episode lists (1..N) with playback video URLs.
ts
12345 
const tokkit = await TokKit.create();

// Access all short drama APIs
const trending = await tokkit.shortDrama.getTrending();
const episodes = await tokkit.shortDrama.getEpisodes('7428819203');

Trending & Ranking

Fetch top ranked and trending miniseries from TikTok's Short Drama charts.

Usage

ts
12345678 
// Fetch Top Trending short dramas
const trending = await tokkit.shortDrama.getTrending({ cursor: 0, count: 18 });

// Fetch Top Ranked short dramas
const ranking = await tokkit.shortDrama.getRanking({ cursor: 0, count: 18 });

console.log(trending.series[0].title, trending.series[0].coverUrl);

Parameters

cursor (number)
  • Description: Pagination offset index.
  • Default: 0
count (number)
  • Description: Number of items to retrieve per page.
  • Default: 18

Genres & Themes

Filter short dramas across 18 genres, 28 story themes, and release dates.

1. Fetch Categories

TikTok provides a dynamic category list via /api/drama/filter/category_list/:

ts
12 
const categories = await tokkit.shortDrama.getCategories();
// categories.genres -> 18 genres (Action, Romance, Werewolf, Fantasy...)

2. Filter Dramas by Tag ID

ts
1234 
const filtered = await tokkit.shortDrama.filter({
  tagIDList: "0,7628991192537158672,0", // Fantasy tag
  count: 18
});

API Reference

Overview of core methods exposed by the TokKit client instance.

Method Module Return Type Description
TokKit.create(opts?) Root Promise<TokKit> Initializes client session and device tokens
shortDrama.getTrending(opts?) Drama Promise<DramaList> Fetch top trending short drama series
shortDrama.getRanking(opts?) Drama Promise<DramaList> Fetch top ranked short drama miniseries
shortDrama.getLatest(opts?) Drama Promise<DramaList> Fetch newly released drama series
shortDrama.filter(opts) Drama Promise<DramaList> Filter dramas by composite genre/theme tag
shortDrama.getEpisodes(id, opts?) Drama Promise<EpisodeList> Retrieve episode playlist and streams
feeds.getForYou(opts?) Feeds Promise<FeedResult> Stream algorithmic For You Page posts
feeds.getExplore(opts?) Feeds Promise<ExploreResult> Browse 21 categories discovery feed
feeds.searchLive(q) Feeds Promise<LiveResult> Search active live stream broadcasts
resolver.resolve(url) Resolver Promise<VideoInfo> Resolve direct MP4 stream without watermark

Error Handling

TokKit exports strongly-typed error classes to catch bot blocks and network issues.

Try / Catch Pattern

ts
123456789 
import { TokKit, WafBlockError } from '@odion-cloud/tokkit.js';

try {
  const data = await tokkit.shortDrama.getTrending();
} catch (err) {
  if (err instanceof WafBlockError) {
    console.error('TikTok WAF captcha block encountered');
  }
}
